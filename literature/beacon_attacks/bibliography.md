# Bibliography

Compiled 2026-09-04. Citations verified against Europe PMC and Crossref unless marked otherwise.
Verify every new citation against one of those indices before adding it: subagent-supplied
citations were wrong four times while this review was written, including two DOIs that resolved to
the wrong paper. This file doubles as the record of what has not been read, via the tags below.

Confidence key:

- **[V]** metadata verified against Europe PMC or Crossref, and the paper's own text was read.
- **[M]** metadata verified, but only the abstract or a summary was read.
- **[U]** unverified lead. Found via search, metadata not confirmed against an index. Treat with care.
